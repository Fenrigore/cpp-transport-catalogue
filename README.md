# Транспортный справочник с маршрутизацией и визуализацией (C++17)

Приложение для управления данными транспортной сети, расчета кратчайших маршрутов между остановками и генерации векторных карт (SVG). Проект демонстрирует применение современных возможностей C++17, алгоритмов на графах и модульной архитектуры.

## 🚀 Ключевые особенности и Архитектурные решения

### 🗺️ Модульная архитектура
Кодовая база разделена на независимые слои: `domain` (бизнес-модели), `catalogue` (хранение и индексация), `router` (построение графов и маршрутизация), `render` (генерация SVG) и `json` (парсинг и сериализация). Это обеспечивает слабую связанность компонентов.

### 🚀 Оптимизация работы с памятью
- Использование `std::deque` для хранения основных сущностей (`Stop`, `Bus`), что гарантирует стабильность указателей при добавлении новых элементов и позволяет безопасно использовать их в хэш-таблицах.
- Применение `std::string_view` для передачи строк в функции поиска и добавления, что исключает лишние аллокации и копирование памяти.

### ⚡ Кэширование вычислений (Memoization)
Расчет расстояний между остановками выполняется при первом запросе, а результаты сохраняются в кэш. Для этого используются `mutable std::unordered_map` с кастомным хэш-функтором (`DistanceHasher`), оптимизированным для пар указателей, что снижает вычислительную нагрузку при повторных обращениях.

### 🕸️ Маршрутизация на графах
Транспортная сеть моделируется как ориентированный взвешенный граф (`DirectedWeightedGraph`). Ребра графа содержат не только вес, но и семантические данные (`bus_route`, `span_count`). Реализован эффективный маппинг указателей на остановки в `VertexId` для быстрого поиска пути.

### 🎨 Генерация векторных карт (SVG)
Собственный рендер-движок включает класс `SphereProjector`, который анализирует границы всех координат маршрутов и вычисляет коэффициент масштабирования. Это позволяет корректно проецировать географические координаты на 2D-плоскость SVG с учетом заданных отступов.

### 🛡️ Type-Safe JSON
Реализация парсера и билдера JSON на базе `std::variant`. Паттерн Builder позволяет формировать вложенные структуры ответов декларативно и безопасно.
